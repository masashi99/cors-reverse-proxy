# cors-reverse-proxy

このプロジェクトは、リバースプロキシを利用して CORS に対応できることを検証するためのサンプルです。

## 目的

フロントエンドと API が別オリジンで動作する構成において、
リバースプロキシを介して CORS の課題を解消できることを確認します。

## 環境ごとのリバースプロキシ

### ステージング環境向け（`docker-compose` で起動）

`docker-compose` で起動する場合は、`proxy` サービスの **nginx** がリバースプロキシとして動作し、
フロントエンドと API 間の中継を担います。

### 開発環境向け（`custom-element` を Vite で起動）

`custom-element` ディレクトリで Vite 開発サーバーを起動する場合は、
**Vite の proxy 機能** がリバースプロキシとして動作します。
`/api` へのリクエストを API サーバーに転送することで、開発時の CORS 問題を回避します。
